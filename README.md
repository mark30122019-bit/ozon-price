# Ozon Price Adjuster

Serverless-функция для Yandex Cloud Functions, которая автоматически корректирует базовые цены товаров на Ozon Seller API на основе текущей цены для покупателя с Ozon Картой.

Функция запускается по таймеру (например, раз в 10 минут), выполняет один проход без циклов ожидания и завершает работу.

## Как это работает

1. Получает список товаров и цен через `POST /v5/product/info/prices` (с пагинацией).
2. Для каждого товара читает цену с Ozon Картой: `price_indexes.price_with_ozon_card`.
3. Сравнивает её с желаемой рыночной ценой `TARGET_MARKET_PRICE` (по умолчанию 1500 ₽).
4. Если цена с картой ниже целевой — увеличивает базовую цену (`price`) на разницу.
5. Отправляет обновления через `POST /v1/product/import/prices`.

Формула находится в функции `calculate_new_base_price()` в файле `index.py`.

## Переменные окружения

| Переменная | Обязательна | Описание |
|------------|-------------|----------|
| `OZON_CLIENT_ID` | Да | Client-Id из личного кабинета Ozon Seller |
| `OZON_API_KEY` | Да | API-ключ из личного кабинета Ozon Seller |
| `DRY_RUN` | Нет | Если `1` — только расчёт и логи, без отправки цен в Ozon |

### Локально

Секреты хранятся в файле `.env` в корне проекта:

```powershell
copy .env.example .env
```

Откройте `.env` и укажите свои ключи. Файл `.env` добавлен в `.gitignore` и не должен попадать в репозиторий или архив для Yandex Cloud.

### В Yandex Cloud Functions

Переменные задаются в настройках функции в консоли Yandex Cloud (раздел «Переменные окружения»). Файл `.env` в облако загружать не нужно.

Приоритет: если переменная уже задана в окружении, значение из `.env` её не перезапишет.

## Быстрый старт (локально)

### 1. Установка зависимостей

```powershell
cd C:\work\ozon
py -3 -m pip install -r requirements.txt
```

### 2. Настройка `.env`

```powershell
copy .env.example .env
```

Заполните `OZON_CLIENT_ID` и `OZON_API_KEY`.

### 3. Тесты логики (без ключей)

```powershell
py -3 -m unittest discover -s . -p "test_*.py" -v
```

### 4. Локальный прогон с реальным API

Сначала безопасный режим — только расчёт, без изменения цен на Ozon:

```powershell
# В .env раскомментируйте: DRY_RUN=1
py -3 run_local.py
```

Когда убедитесь, что расчёт верный, уберите `DRY_RUN` и запустите снова:

```powershell
py -3 run_local.py
```

## Деплой в Yandex Cloud Functions

1. Создайте функцию с runtime **Python 3.9+**.
2. Загрузите `index.py` и `requirements.txt` (без `.env`).
3. Укажите точку входа: **`index.handler`**.
4. В переменных окружения функции задайте `OZON_CLIENT_ID` и `OZON_API_KEY`.
5. Создайте триггер-таймер, например: `cron(*/10 * * * ? *)` — каждые 10 минут.

Логи выполнения смотрите в Yandex Cloud Logging.

## Настройка целевой цены

Желаемая рыночная цена задаётся константой в `index.py`:

```python
TARGET_MARKET_PRICE = 1500
```

Для изменения логики пересчёта отредактируйте функцию `calculate_new_base_price()`.

## Важно

- У Ozon есть лимиты на обновление цен (около 10 обновлений в час на товар) — учитывайте интервал таймера.
- Поле `price_with_ozon_card` может отсутствовать у части товаров — такие позиции пропускаются с записью в лог.
- Никогда не коммитьте файл `.env` и не включайте его в zip-архив для деплоя.

## Где взять ключи Ozon

[Личный кабинет Ozon Seller](https://seller.ozon.ru/) → **Настройки** → **Seller API** → создать API-ключ. Client-Id указан там же.
